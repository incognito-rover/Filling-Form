Hi, I have created a tool to fill the application form automatically, with an ease of a button
To use this:
1. Download all the files of this repository and Save them in a folder locallly.
2. Open your browser
3. Go to extension page
4. Enable Developer option
5. "Load Unpacked" and select the folder
6. Now your extension will be loaded.
7. Fill the form, (You only need to fill this once )
